# 农田统计与空间格局数据接入

配置文件：`parcelAnalysis.json`。`years` 留空表示没有年度地块数据，不将现有地块冒充任何年份。

接入示例（仅结构示例，不是实际数据）：

```json
{
  "idField": "parcel_id",
  "years": {
    "2024": {"layer": "agri-agent:parcel_2024"},
    "2025": {"url": "/data/parcel_2025.geojson"},
    "2026": {"layer": "agri-agent:parcel_2026", "idField": "parcel_id"}
  }
}
```

`layer` 使用现有 GeoServer WFS；`url` 使用 WGS84 GeoJSON。年度之间必须有一致且唯一的稳定地块编号才能展示新增、消失、扩大及缩小。数据必须覆盖相同研究区；同编号面积变化达到5%归为扩大或缩小，消失不自动认定为弃耕。变化比较以最早可用年份为基准。

统计范围为地图视野，以面积最大的组成面的内部点决定地块是否计入，计入完整地块面积。面积及边界长度采用 OpenLayers 球面计算，边界长度包含孔洞；密度为地块数量/视野面积，边界密度为总地块边界长度/视野面积（共享边界分别计入各地块，不进行拓扑去重）。经纬度网格大小0.05°，按每个网格真实球面面积换算密度，不是固定公里方格；平均面积为网格内总地块面积/地块数。占比为含地块网格数量占比，空网格不计入。

年度折线图对同一地图视野重新计算。迁移线采用按地块面积加权的内部点重心，属于当前视野的描述统计，不代表全流域重心。聚合度、连片核心区、破碎化热点需要数据负责人确定算法与统计尺度后提供结果，当前明确显示暂无数据。

WFS单次超过6000个要素会提示放大地图，不把截断样本作为完整统计。GeoJSON文件必须为完整交付数据；页面不会自动验证文件覆盖范围和地块编号的跨年一致性。
